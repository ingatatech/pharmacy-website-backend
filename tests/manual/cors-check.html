How to actually test both outcomes

  1. Start the backend with FRONTEND_URL=http://localhost:3000 (the default in .env.example).
  2. Allowed origin: serve this exact file from port 3000 and open it in a browser: 
    npx serve tests/manual -l 3000
    then visit http://localhost:3000/cors-check.html and click the button. Expect: success, JSON printed.
  3. Unauthorized origin: serve the same file from a different port instead: 
    npx serve tests/manual -l 5500
    then visit http://localhost:5500/cors-check.html and click the button. Expect: failure — open the browser's DevTools Console to see the actual blocked by CORS policy error. The Network tab will show the request still reached the server and got a 200 back — the browser is what refused to hand the response to this page's JavaScript, which is the whole point: CORS protects browsers from malicious pages, it is not a server-side access check.
